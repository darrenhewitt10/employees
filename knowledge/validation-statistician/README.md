# Knowledge: Greta (validation-statistician)

Greta reads this folder before every answer. Put material here that should shape Greta's answers but doesn't belong in the shared research in `docs/`.

**Role:** Independent validation statistician (red team).

## What belongs here
- Validation reports and verdicts
- Trial logs or their summaries
- Known data issues and biases found before
- Statistics references (DSR, PBO, CPCV)

## What does not belong here
- Secrets of any kind: API keys, passwords, account numbers, SSNs or tax IDs.
- Licensed vendor data (price files, data feeds); link to where it lives instead.
- Material for every agent: put it in `docs/` so the whole team sees it.

## Conventions
- Markdown preferred (`.md`); PDFs and CSVs are fine for source material.
- Name files `YYYY-MM-DD-short-topic.md` so the newest is easy to find.
- Start each file with one line saying what it is, where it came from and when.
- Delete or mark superseded files instead of keeping conflicting versions.
